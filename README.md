# Snek: Surfacing Artifacts from AutoML

## Install Dependencies and Run Frontend Dev Server
* `cd frontend`
* `npm install`
* `npm run watch`

## Install Python Requirements
* `pip (or pip3) install -r requirements.txt`

## Set Debug Mode On
* `export FLASK_DEBUG=1`

## Run Flask Server
* `env FLASK_APP=app.py flask run`
